# <center> 作业二
作业要求：
1. 使用Socket和多线程编写聊天程序。
2. 包含服务器（server）和客户端（client）两个多线程程序。
3. 一个线程负责接收并显示对方消息，另一个线程负责处理本方输入。

实现步骤：
- 构建程序并编译
1. 创建homework2/目录
2. 创建并编写server.ce和client.c两个程序，源码与分析请见代码
3. 创建并编写CMakeLists.text
4. 在homework2/中使用`cmake -s ./`命令进行编译
5. 在homework2/中使用`make`命令进行生成
- 程序运行
1. 在homework2/中使用`./server`命令打开服务器，其会显示“服务器启动，等待连接”
2. 新启终端，在homework2/中使用`./client 127.0.0.1`命令打开客户端，服务器终端会显示“客户端已连接”
3. 开始聊天，接收方会以“receive:”开头
- 提交到远程仓库
